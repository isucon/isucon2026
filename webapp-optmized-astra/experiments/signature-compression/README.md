# 署名計算の比較候補（未配備）

画像署名のキャッシュミス時に、最初のHMACは既存ライブラリで計算し、残り999回の固定32バイト入力をSHA-256圧縮関数で計算する候補。鍵ごとのinner/outer状態を作り、96バイトの長さとpaddingを固定する。署名方式・反復回数・URLの期限は変えない。

既存のPython/Go共通ベクトル、0/1/32/64/65/128バイト鍵、Unicode画像ID、期限の境界、改ざん・期限切れ拒否の4テストが成功した。ローカルreleaseで1,000個の未キャッシュ署名を交互に6回測り、中央値は既存約77.0ms、候補約70.1msだった。実機スコアは未測定。独自の低水準処理を増やすため、現在は署名キャッシュの計測・重複計算集約を優先し、この候補は配備しない。

再計測: `cargo test --release --lib compare_uncached_signature_cost -- --ignored --nocapture`
