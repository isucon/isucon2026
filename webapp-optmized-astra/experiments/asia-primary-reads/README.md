# アプリ改善後のAsia主DB読み取りの再比較

3台同期は総合スコアが上がらず2台同期へ戻し、181,005点でPASSした。現在のアプリでは画像本文の処理枠と応答待ちを分離し、通知SQL・署名・画像保存なども改善済み。以前の負荷配分を前提に採用したAsiaの読み取り分散を再比較する。

最初はasiaReplicaReadsだけをfalseにし、Asiaの全読み取りを既存db1へ戻す。追加の物理レプリカは動かしたまま保持する。EU・USの地域内読み取りと、更新応答前の2台への同期反映は維持する。主DBのCPU増加と、Asiaの読み取り前確認・I/O負荷の減少を、同じseedと反復で比較する。

候補は未測定。直前の2台同期の結果は185,395点・184,915点、3台同期比較後の切り戻しは181,005点で、すべてPASS。配布物は変更せず、設定をPulumiと配備スクリプトから反映する。新しいAWSリソースは作らない。
