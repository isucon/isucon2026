このディレクトリのlibtests.txt、regression.txt、clippy.txt、release.txtは初期候補cf0a9a59の検証記録として残す。初期候補は実DBで旧SQLとの一致、50件制限、ページ送り、状態変更、コミット順の逆転、ロールバック、初期化を検証した。撤回後のmemory_batch_tests.rsは、旧SQLとの結果一致に加え、018→019を繰り返し適用して台帳が残らないことを検証する。

基準走行025003は結果回収中にAWS認証が失効したが、再認証後に既存結果を回収済み。再実行やベンチの変更はしていない。配備前の旧アーカイブと一致するハッシュをexperiment.jsonへ記録した。
