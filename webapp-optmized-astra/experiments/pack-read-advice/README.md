# 画像パックの読み出し範囲

初期画像のパックは大きなファイルから画像ごとの小さな範囲を読む。Linuxの既定の先読みが隣接画像まで読み込む可能性があるため、パックのファイルハンドルへPOSIX_FADV_RANDOMを指定する候補を比較する。新規画像ファイル、DB、端末全体の設定は変更しない。読み出し範囲・本文・権限確認は同じ。

[Linux man-pages](https://www.man7.org/linux/man-pages/man2/posix_fadvise.2.html)によると、この指定は対象ハンドルの先読みを停止する。アクセスパターンによっては遅くなるため、ローカルの専用一時ファイルと実機ベンチで比較する。アドバイスが利用できなくても通常の読み出しを続ける。

専用256MiBファイルの8KiB範囲4,096件を、毎回openして読むローカル比較では、物理読み取り量は通常48,607,232バイト、random指定45,703,168バイトだった。全読み出しのハッシュは一致。通常0.698秒・0.534秒、random 0.773秒・0.586秒で、速度の改善は確認できなかった。範囲読み取りの既存テスト2件とClippyは成功。実機へは未配備。候補ブランチに留める。
