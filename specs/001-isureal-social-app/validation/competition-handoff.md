# 競技機能への引き継ぎゲート

記録日: 2026-07-19 (UTC)

## Release gate

このfeatureが承認し、実装し、検証した範囲は、正しい基準ソーシャルアプリとその自動テストまでである。以下の作業は現featureでは認可されておらず、要件、受入条件、セキュリティ/公開範囲、検証計画を持つ「別の承認済みfeature specification」が必須である。

- benchmarkの作成、負荷モデル、score、合否基準の導入
- bottleneckの設計・導入、registry、意図した解法の設定
- 個別bottleneckの単独較正と、組み合わせた累積較正
- 試し解き、難易度/時間/得点バランスの調整
- 競技用資産の生成、パッケージ化、配布、公開前監査

このゲートは、上記のコード、設定、数値、ドキュメントを現featureの成果物へ追加しないことも要求する。

## 強制する順序

別featureの承認後も、作業は次の順序でのみ進める。

1. 基準実装と自動テストを`version-manifest.md`の固定点から再現する。
2. ベンチマーカーを作成し、基準実装での正しさと安定性を検証する。
3. 承認されたbottleneckを1つずつ導入する。
4. 各bottleneckを単独較正し、次に全体の累積較正を行う。
5. 隔離環境で試し解きし、意図しない解法・情報漏洩・回帰を解消する。
6. 公開成果物のsecret、個人情報、解法spoiler、version整合性を配布監査してから配布する。

つまり、必須の順序は「基準実装とテスト → ベンチマーカー → ボトルネック導入 → 単独・累積較正 → 試し解き → 配布監査」である。前段が承認済みでない場合、後段に進んではならない。

## 現在の判定

- 基準実装・テスト・公開成果物監査: PASS
- 競技化の別feature specification: 未承認/未定義
- benchmark以降の競技作業: BLOCKED BY RELEASE GATE
