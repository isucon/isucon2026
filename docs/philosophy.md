# ISUCON 2026 作問における指針

## コーディングエージェントの発展とISUCONという競技の難しさ

前回のISUCONから2年の間にコーディングエージェントは大きく進歩し、従来のISUCONの問題は容易に解かれるようになった。
例えば、Claude CodeにISUCON 14の問題を解かせたところ、当時の優勝スコアを上回るスコアが出たという[報告](https://kyosu.dev/blog/isucon14-with-claude-code/)もある。

このような状況下で、ISUCONを「コーディングエージェントにかけた費用の勝負」ではなく競技として楽しめるものにするには、
AIを使ってもなお人間の主導（ドライブ）が重要になる問題にするか、あるいはAIの使用自体を禁止するかのいずれかの方向性が必要だと考えた。

ISUCON 2026では前者の方針を採り、AIの使用を禁止せずむしろ前提としたうえで、AIに任せきりでは太刀打ちできない方向性で問題を作成することとした。
